# 工作笔记

最初写这三段脚本时的思路和遗留问题，留着方便回头看。

## 三个脚本各自的活

1. **坐标提取**：把视频转成结构化数据。视频内容是中风患者的肢体运动，代码把画面里的人体关键点逐帧转成三维坐标，存成 CSV。

2. **上肢评定**：生成的坐标数据有上肢和下肢两类，先把它们区分开，再把上肢数据按 FMA 量表和标准转成评分和分析。可视化也做了，但做得比较粗。

3. **下肢评定**：同理，处理下肢的坐标并输出结果。

## 当时发现的问题

- 坐标提取这一块还需要改，有些测试视频还是提不出三维数据。
- 希望能直接用代码区分上肢和下肢的提取，不用人工分文件夹。

现在第一点已经在 `extract_coordinates.py` 里处理了一部分：检测失败的帧不再填空值硬凑，而是留空并统计有效率，分析脚本再把无效帧丢掉。第二点做成了 `--landmarks upper|lower` 参数，取哪几类点由命令行指定。

还有没解决的部分：动作类型和患侧仍然要人工告诉程序。
